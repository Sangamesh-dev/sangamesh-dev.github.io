TRIAGEAI.

LLM-assisted SOC alert triage with MITRE ATT&CK mapping.

A triage assistant for security analysts. It ingests SIEM alerts, groups near-duplicates with FAISS vector search, maps each one to MITRE ATT&CK techniques and has Groq's llama-3.3-70b score and prioritise them. Results appear in a React, Vite and FastAPI dashboard. Still in development.
