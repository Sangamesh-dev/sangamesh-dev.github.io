REDTEAM COPILOT AI.

An automated recon-to-report pentest assistant.

A FastAPI service that automates the recon-to-report part of a penetration test in four fixed stages: OSINT (DNS records, a subdomain wordlist, crt.sh and WHOIS), an nmap service scan, CVE lookups against the NVD with CISA KEV escalation, and a Groq-written report rendered as a PDF and stored in Supabase. A React front end streams progress as the scan runs. CVE matches are keyword lookups to review, not confirmed vulnerabilities.

What I built

  • Built the four-stage pipeline as a FastAPI background task, streaming live progress to the React UI over server-sent events.
  • Implemented OSINT (DNS, crt.sh, WHOIS and a subdomain wordlist), nmap service scanning, and NVD CVE lookups with CISA KEV escalation.
  • Generated PDF reports with ReportLab from Groq-written analysis, stored in Supabase.
