ZEROTRACE AI.

Threat intelligence with exploit prediction.

A threat-intelligence platform that merges CVE feeds from NVD, CISA KEV and ExploitDB into one risk-ranked view. An XGBoost model estimates how likely each vulnerability is to be exploited, the Groq API summarises advisories, and FAISS powers semantic search. Streamlit, FastAPI, PostgreSQL and Docker.

What I built

  • Built ingestion for CVE feeds from NVD, CISA KEV and ExploitDB into one risk-ranked pipeline.
  • Trained the XGBoost exploit-prediction model on CVSS score, exploit availability, CWE category and vendor data.
  • Added FAISS semantic CVE search and Groq-generated advisory summaries.
