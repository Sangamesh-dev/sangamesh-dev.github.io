PREDICTIVE PATCH SCHEDULER.

Patch scheduling from rule-based and ML risk scores.

A FastAPI app that turns vulnerability records (entered by hand, uploaded as CSV or JSON, or generated as sample data) into a patch schedule. A deterministic rule scores risk from CVSS, exploit availability and system criticality. An optional ML path (Random Forest for risk, Gradient Boosting for priority) is trained on synthetic data labelled by the same rule, so it approximates the rule rather than replacing it. Priority sets the patch window, from 24 hours for critical to 14 days for low, and a dashboard shows Plotly analytics with WebSocket alerts.
