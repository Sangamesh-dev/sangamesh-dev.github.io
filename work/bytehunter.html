BYTEHUNTER.

Malware triage for Windows executables, with one model deciding the verdict.

A FastAPI and React malware-triage app. Uploaded files are hashed and cached by SHA-256, parsed with LIEF into a 2,381-value feature vector and scored by the pre-trained EMBER 2018 LightGBM model. One threshold scale turns that score into SAFE, SUSPICIOUS or MALICIOUS, with a heuristic scorer as the fallback when the model isn't available. Random Forest and Logistic Regression add an agreement check, an XGBoost model trained on Microsoft BIG-2015 suggests a malware family for high scores, and SHAP-based explanations are summarised as text. Results are stored in SQLite and exported as PDF reports.

What I built

  • Built the scan API: batch upload, SHA-256 caching, LIEF feature extraction into a 2,381-value vector, and verdict thresholds on the LightGBM score.
  • Trained an XGBoost family classifier on Microsoft BIG-2015 and Random Forest and Logistic Regression comparison models, and added SHAP-based explanations.
  • Added a heuristic fallback scorer, SQLite scan history and ReportLab PDF reports.
